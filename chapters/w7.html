🌲 分類與決策樹

分類（Classification）是從有類別標籤的資料學出一個函數 \(f: X \to Y\)，再用它預測新資料的類別；決策樹是其中最直觀的分類器，從根節點一路問屬性問到葉節點，就得到預測。

  • 分類是監督式學習（Supervised learning）：訓練集擬合模型、驗證集選模型與超參數、測試集只做最後評估。
  • 決策樹由上而下、遞迴、貪婪地建：每個節點挑一個讓子節點「最純」的屬性來切。
  • 三種挑屬性的量度：資訊增益（ID3）、增益比（C4.5）、Gini 不純度（CART）。
  • 講義範例：14 筆 buy_computer 資料，Gain(age) = 0.246 最大，所以根節點是 age。

1. 本章摘要

  • 分類的流程分兩階段：① 學習／訓練：用訓練集建分類器，用驗證集選模型與超參數；② 評估與預測：用沒看過的測試集評估，結果可以接受才拿去分類新資料。
  • 決策樹（Decision Tree）是長得像流程圖的分類器：內部節點測試一個屬性、分支是測試結果、葉節點是預測的類別。
  • 資訊增益（Information gain）偏好分支多的屬性；增益比（Gain ratio）除以分割資訊（SplitInfo）來修正；Gini 不純度（Gini impurity）看依類別分布隨機貼標籤時貼錯的機率。
  • 決策樹好解釋、幾乎不用前處理，但變異大、容易過度配適，而且貪婪分割只是局部最佳。

2. 核心概念

2.1 分類是什麼（第 6～9 頁）

分類是從有標籤的範例學習：每個物件有屬性（特徵）和一個類別標籤，目標是給一個類別未知的新物件，預測它屬於哪一類。

  • 類別標籤也是屬性：其中一個屬性被指定為類別標籤（目標屬性, target attribute）。例：影像特徵是顏色、形狀、紋理；類別標籤是 Cat 或 Dog。
  • Pokémon 例子：屬性是顏色、耳朵形狀、尾巴形狀、體型…；類別標籤是 Pikachu、Bulbasaur、Charmander…
  • 在資料探勘裡，學到的分類器本身就是一種「有趣的樣式」：它描述了屬性和類別標籤之間的關係。
  • 訓練資料：\(D_{train} = \{(x_i, y_i)\}_{i=1}^{n}\)，\(x_i \in X\) 是物件 i 的特徵向量，\(y_i \in Y\) 是它的類別標籤。X 是特徵空間，Y 是所有可能類別的集合。
  • 特徵向量是 d 維的：\(x_i = (x_{i1}, x_{i2}, \dots, x_{id})\)；類別標籤是離散或名目（nominal）值。
  • 分類就是學一個分類器 \(f: X \to Y\)。新物件 \(x_z\) 的預測類別是 \(\hat{y}_z = f(x_z)\)。

2.2 分類的兩個階段（第 10～11 頁）

  1. 學習／訓練（監督式學習）：用 \(D_{train}\) 建分類器。可能學出好幾個候選 \(f_1, f_2, \dots, f_m\)，哪個最好？不能偷看測試集，要用驗證資料（validation data）來選模型和超參數。
  2. 評估與預測：在保留的（held-out）測試資料上評估。測試資料在學習和選模型時都沒用過，但真實標籤已知：對每筆預測 \(\hat{y}_t = \hat{f}(x_t)\)，再和真實標籤 \(y_t\) 比對。結果可以接受，才用模型分類新資料。

2.3 訓練集、驗證集、測試集（第 12 頁）

訓練集用來擬合模型參數，驗證集用來選模型、調超參數，測試集只做最後評估；三者不能混用。

  • 超參數例子：樹的深度、k-NN 的 k、SVM 的 C 和 γ、神經網路的架構。
  • 講義的切法：先把 D 切成 80% 與 20%（測試集），再把 80% 那份切成 80% 訓練、20% 驗證。
  • 補充換算回整份資料：訓練 64%、驗證 16%、測試 20%。
資料集用途例子
訓練集（Training set）擬合模型參數決策樹的分割、SVM 的權重
驗證集（Validation set）選模型、調超參數樹深度、k-NN 的 k、SVM 的 C 和 γ
測試集（Test set）只做最後評估回報最終準確率

2.4 做分類任務時要決定的四件事（第 14～16 頁）

  1. 用哪些特徵？特徵擷取（feature extraction）與特徵選取（feature selection）。
  2. 用哪個分類演算法、哪些超參數？深度學習還要決定架構、激活函數、學習率、批次大小…
  3. 怎麼切分有標籤的資料？訓練、驗證、測試集。
  4. 怎麼評估模型表現？
  • 樂器辨識例子：輸入是一段音訊 x，輸出是 piano、guitar、violin…。特徵可用 MFCCs、spectral centroid、Whisper；演算法可用 SVM、決策樹、2D CNN；切分 80% 訓練、20% 測試；評估用準確率（Accuracy）。
  • 本課程會教的分類方法：決策樹、單純貝氏分類器（Naïve Bayes）、K 最近鄰（K-Nearest-Neighbors）、案例式推理（Case-Based Reasoning）、邏輯斯迴歸（Logistic Regression）、支援向量機（SVM）、集成分類器（Ensemble Classifiers）。

2.5 決策樹（第 18～20 頁）

決策樹是以流程圖形式表示的分類器：每個內部節點測試一個屬性，每個分支對應一個測試結果，每個葉節點預測一個類別標籤。

  • 分類新資料：從根節點開始，沿著符合的分支一路走到葉節點。
  • 建樹：一開始所有訓練資料都在根節點，依選出的屬性遞迴地分割。
  • 每個節點用「落在這個節點的訓練資料」和一個啟發式或統計量度來挑屬性。

2.6 為什麼需要「純度」（第 54～55 頁）

  • 好的分割讓子節點盡量純。純節點（pure node）只包含一種類別。
  • 第 54 頁例子：用 student 分，如果 yes 那邊 6/6 都是買、no 那邊 6/6 都是不買，就完全分開；如果兩邊都是 3/6 對 3/6，等於沒分。
  • 熵（Entropy）由 Bell Labs 的 Claude E. Shannon 提出，衡量類別的不確定性：純的時候是 0，類別平均混合時最大。

熵與 Gini 計算器

3. 演算法與方法

3.1 通用決策樹演算法（第 36、47 頁）

決策樹歸納是遞迴的：純的就停、沒屬性可用就停，否則挑最好的屬性切開，對每一份再做一次。

  • 純節點 → 葉節點，標籤就是那個類別（第 38 頁：\(D_{middle}\) = {yes, yes, yes, yes} → yes）。
  • 沒有候選屬性 → 葉節點，標籤用多數類別（第 39 頁：{yes, yes, yes, no} → yes）。
  • 某個分支沒有任何資料 → 葉節點，標籤用父節點的多數類別。
BuildTree(D, 候選屬性):
    建立節點 N，包含 D
    if D 全部同一類別 C:   return 葉節點 C          # 純節點
    if 沒有候選屬性:        return 葉節點 majority(D) # 多數類別
    A = 依屬性選擇準則挑出最好的屬性
    for A 的每個值 a:
        Dₐ = D 中 A = a 的資料
        if Dₐ 是空的: 接上葉節點 majority(D)
        else:         接上 BuildTree(Dₐ, 候選屬性 − {A})
    return N

3.2 屬性怎麼分割節點（第 45～46 頁）

  • 類別屬性、多路分割（multiway）：每個值一個分支（ID3、C4.5）。
  • 數值屬性：用門檻值切成 ≤ t 和 > t 兩邊（threshold split）。
  • 類別屬性、二元分割：把值分成兩個子集（value-subset split），CART 用這種。
  • 分割後要更新候選屬性清單：離散屬性在任一條從根到葉的路徑上最多用一次；數值屬性可以在不同門檻下重複使用。
  • 連續屬性的兩種處理：① 離散化（Discretization），例如 age 切成 < 20、20..30、30..40、40..50、> 50；② 在節點上學門檻：把值排序，相鄰兩值的中點就是候選分割點。

連續屬性的門檻

講義第 46 頁的 age 值：15, 18, 21, 22, 24, 25, 29, 31 → 候選分割點 16.5, 19.5, 21.5, 23, 24.5, 27, 30。點圓點切換它的類別，看哪個門檻的資訊增益最大。補充預設類別 no, no, no, yes, yes, yes, yes, no 是自己設的，講義沒給 → 最佳門檻 21.5，Gain 0.549。

3.3 資訊增益（Information Gain, ID3）

資訊增益是「分割前的熵」減去「分割後各分支熵的加權平均」：切完之後不確定性降了多少。ID3 選資訊增益最大的屬性。

  • Info(D)：分割前，D 的類別分布的熵。
  • \(Info_A(D)\)：依屬性 A 切成 \(D_1, \dots, D_v\) 後，各分支熵以筆數比例加權的平均。
  • \(Gain(A) = Info(D) - Info_A(D)\)，越大越好。
  • 歷史：J. Ross Quinlan 在 1986 年的論文〈Induction of Decision Trees〉提出 ID3，建立在更早的概念學習系統（Concept Learning System, CLS）之上。

3.4 增益比（Gain Ratio, C4.5，第 62～65 頁）

增益比是把資訊增益除以分割資訊（SplitInfo），用來懲罰分支太多的屬性。C4.5 選增益比最大的屬性。

  • 資訊增益的缺點：偏好分支多的屬性。極端情況是用唯一識別碼（ID）分割，每支只有 1 筆、熵都是 0，資訊增益最大，但完全沒有預測能力。
  • SplitInfo 只看每個分支的筆數，跟類別標籤無關；分支越多、越平均，SplitInfo 越大。
  • C4.5 是 ID3 的後繼者，另外加上連續屬性、缺失值處理和剪枝（pruning）。

補充增益比也擋不住純 ID：14 筆資料用 ID 分割，Gain = 0.940、SplitInfo = \(\log_2 14\) = 3.807、GainRatio = 0.247，仍然大於 age 的 0.156。C4.5 實作上的補救是：只在資訊增益至少達到平均值的屬性中挑增益比最大的。可以在下面兩個元件勾「加入 ID 屬性」看看。

3.5 Gini 不純度（Gini Impurity, CART，第 66～67 頁）

Gini 不純度是依照節點的類別分布隨機貼標籤時，貼錯的機率；純的時候是 0，越混越大。

  • 3 類例子：全部是 A → Gini = 0；A 30%、B 40%、C 30% → 0.3×0.7 + 0.4×0.6 + 0.3×0.7 = 0.66。
  • CART（Classification and Regression Trees）是 Breiman、Friedman、Olshen、Stone 在 1984 年出版的書，建的是二元決策樹。
  • 補充CART 的類別屬性要列舉值的子集：v 個值有 \(2^{v-1} - 1\) 種二元切法，選加權 Gini 最小的；屬性之間比的是 Gini 下降量 \(\Delta Gini\)，越大越好。

待確認講義文字只擷取到第 67 頁（Gini index 的定義才開頭），之後的內容（Gini 分割的計算，可能還有過度配適與剪枝）沒擷取到。本頁 Gini 分割的數字是 補充依課本、用同一份 14 筆資料算的，請對照原始投影片。

3.7 決策樹的優缺點（第 48～49 頁）

優點缺點
可解釋：預測可以寫成 if–then 規則高變異（high variance）：訓練資料小改一點，樹就可能不一樣
幾乎不用前處理，通常不需要特徵縮放樹長太深會過度配適（overfit）
能處理類別與數值屬性貪婪分割只是局部最佳，不是全域最佳
適用各種屬性類型單一棵樹的準確度可能不如集成方法

4. 公式整理

4.1 熵（第 56 頁）

$$H(M) = -\sum_{i=1}^{n} p(m_i) \log_2 p(m_i)$$

\(p(m_i)\) 是符號 \(m_i\) 出現的機率；約定 \(0 \log_2 0 = 0\)。兩類別時最大值是 1，k 類別時是 \(\log_2 k\)。

4.2 資訊增益（第 57 頁）

$$Info(D) = -\sum_{i=1}^{m} p_i \log_2 p_i, \qquad Info_A(D) = \sum_{j=1}^{v} \frac{|D_j|}{|D|}\, Info(D_j)$$ $$Gain(A) = Info(D) - Info_A(D)$$

4.3 增益比（第 63 頁）

$$SplitInfo_A(D) = -\sum_{j=1}^{v} \frac{|D_j|}{|D|} \log_2 \frac{|D_j|}{|D|}, \qquad GainRatio(A) = \frac{Gain(A)}{SplitInfo_A(D)}$$

4.4 Gini 不純度（第 67 頁）

$$Gini(D) = \sum_{i=1}^{m} p_i (1 - p_i) = 1 - \sum_{i=1}^{m} p_i^2$$

補充二元分割：\(Gini_A(D) = \frac{|D_1|}{|D|} Gini(D_1) + \frac{|D_2|}{|D|} Gini(D_2)\)，\(\Delta Gini(A) = Gini(D) - Gini_A(D)\)。兩類別時最大值 0.5，k 類別時 \(1 - 1/k\)。

4.5 連續屬性的候選分割點（第 46 頁）

$$t_i = \frac{a_i + a_{i+1}}{2}$$

4.6 準確率（第 15 頁）

$$Accuracy = \frac{\#\ \text{correctly classified test samples}}{\#\ \text{test examples}}$$

例一：熵的三個小例子（第 56 頁）

  1. \(M_1 = \{m_1, m_2\}\)：各 1/2 → \(H = -(\frac{1}{2}\log_2\frac{1}{2} + \frac{1}{2}\log_2\frac{1}{2}) = 1\)
  2. \(M_2 = \{m_1, m_1, m_2\}\)：2/3、1/3 → \(H = -(-0.39 - 0.53) = 0.92\)
  3. \(M_3 = \{m_1, m_1, m_1\}\)：3/3、0/3 → \(H = 0\) 類別越平均熵越高，越被單一類別主導熵越低。可以在上面的熵計算器按講義例子驗算。

例二：根節點選哪個屬性（第 58～60 頁）

  1. 14 筆中 yes 9、no 5：\(Info(D) = -\frac{9}{14}\log_2\frac{9}{14} - \frac{5}{14}\log_2\frac{5}{14} = 0.940\)
  2. 依 age 分：youth 5 筆（yes 2、no 3）、middle 4 筆（yes 4、no 0）、senior 5 筆（yes 3、no 2）
  3. \(Info_{age}(D) = \frac{5}{14} \times 0.971 + \frac{4}{14} \times 0 + \frac{5}{14} \times 0.971 = 0.694\)
  4. \(Gain(age) = 0.940 - 0.694 = 0.246\)
  5. 同樣算出 Gain(income) = 0.029、Gain(student) = 0.151、Gain(credit_rating) = 0.048 age 最大，當根節點。

例三：增益比（第 64～65 頁）

  1. age 的分支大小 5、4、5：\(SplitInfo_{age}(D) = -\frac{5}{14}\log_2\frac{5}{14} - \frac{4}{14}\log_2\frac{4}{14} - \frac{5}{14}\log_2\frac{5}{14} = 1.577\)
  2. \(GainRatio(age) = 0.246 / 1.577 = 0.156\)
  3. income 分支 4、6、4 → SplitInfo = 1.557 → GainRatio = 0.019
  4. student 分支 7、7 → SplitInfo = 1.0 → GainRatio = 0.151；credit_rating 分支 8、6 → SplitInfo = 0.985 → GainRatio = 0.049 增益比最大的仍然是 age，根節點不變。

例四：往下長（第 37～44 頁）

  1. 用 age 切成三份：\(D_{youth}\) 5 筆、\(D_{middle}\) 4 筆、\(D_{senior}\) 5 筆
  2. \(D_{middle}\) = {yes, yes, yes, yes} 是純節點 → 葉節點 yes
  3. \(D_{youth}\) 不純，候選屬性剩 {income, student, credit_rating}：income → {no, no}、{no, yes}、{yes}；student → {no, no, no}、{yes, yes}；credit_rating → {no, no, yes}、{no, yes}
  4. student 兩邊都純，最好 補充在 \(D_{youth}\) 上：Gain(student) = 0.971、Gain(income) = 0.571、Gain(credit_rating) = 0.020。可以在評分表切到 D_youth 驗算。
  5. 補充\(D_{senior}\)（yes 3、no 2）：credit_rating 把它切成 fair → 3 筆 yes、excellent → 2 筆 no，兩邊都純，Gain = 0.971
  6. 完成的樹（第 22 頁）：age → youth 看 student（no → NO、yes → YES）；middle → YES；senior 看 credit_rating（fair → YES、excellent → NO）

例五：用樹預測新顧客（第 23～26 頁）

  1. 顧客 1：age = middle、income = high、student = no、credit = excellent → age = middle → yes income、student、credit_rating 都沒用到：決策樹只看路徑上的屬性。
  2. 顧客 2：age = senior、income = medium、student = no、credit = excellent → senior → credit = excellent → no
  3. 顧客 3：age = youth、income = low、student = no、credit = fair → youth → student = no → no

例六：Gini（補充依課本）

  1. \(Gini(D) = 1 - (\frac{9}{14})^2 - (\frac{5}{14})^2 = 0.459\)
  2. income 的三種二元切法：{low, medium} | {high} = 0.443、{medium, high} | {low} = 0.450、{low, high} | {medium} = 0.458
  3. 以 {low, medium}（10 筆：yes 7、no 3）| {high}（4 筆：yes 2、no 2）為例：\(\frac{10}{14}(1 - 0.7^2 - 0.3^2) + \frac{4}{14}(1 - 0.5^2 - 0.5^2) = 0.443\)
  4. 各屬性最好的切法：age {youth, senior} | {middle} = 0.357；student 0.367；credit_rating 0.429
  5. age 的 Gini 最小（\(\Delta Gini\) = 0.459 − 0.357 = 0.102 最大） CART 的根節點也是 age，但切成二元：middle 一邊、youth 和 senior 另一邊。

7. 複習問題

7.1 選擇題

1. 要決定 k-NN 的 k 值，應該看哪一份資料上的表現？

(C)。k 是超參數，用驗證集挑。測試集只能做最後評估，拿來選 k 會讓報告的準確率過度樂觀。

2. 一個節點有 yes 4 筆、no 4 筆，它的熵和 Gini 各是多少？

(B)。兩類別平均時熵最大是 1，Gini = 1 − 0.5² − 0.5² = 0.5。

3. 增益比（Gain ratio）主要是為了修正資訊增益的哪個問題？

(D)。分支越多、每支越小越容易純，資訊增益就越大；增益比除以 SplitInfo 來懲罰這種情況。

4. 決策樹建到某個節點，剩下 {yes, yes, yes, no}，而且已經沒有候選屬性了，這個節點會變成？

(A)。講義第 39 頁：沒有候選屬性時，用多數類別當葉節點的標籤。

7.2 觀念題

1. 決策樹的通用演算法在哪三種情況下停止？葉節點的標籤各怎麼決定？

看解答
(1) 節點裡的資料全部同一類別 → 用該類別；(2) 沒有候選屬性可用 → 用節點內的多數類別；(3) 某個分支沒有任何資料 → 用父節點的多數類別。

2. 為什麼離散屬性在一條路徑上最多只用一次，數值屬性卻可以重複用？

看解答
離散屬性用過之後，每個分支裡該屬性的值都一樣，再用一次也切不開。數值屬性用 ≤ t 切完，分支裡的值仍然有大有小，換一個門檻還能繼續切。

3. 一份顧客資料有「顧客編號」欄位，直接丟進 ID3 會發生什麼事？該怎麼處理？

看解答
顧客編號每筆都不同，資訊增益等於 Info(D)、是所有屬性中最大的，ID3 會選它當根節點，每個葉節點只有 1 筆資料，對新顧客完全沒有預測力。應該在前處理時刪掉識別碼欄位；改用增益比也有幫助，但 補充增益比對唯一識別碼仍可能偏高，C4.5 會先排除資訊增益低於平均的屬性。

7.3 計算題

1. 一個節點有 yes 6 筆、no 2 筆，算它的熵和 Gini。

看解答
熵 = −(0.75 log₂0.75 + 0.25 log₂0.25) = 0.311 + 0.5 = 0.811；Gini = 1 − 0.75² − 0.25² = 0.375。可以在熵計算器輸入 6、2 驗算。

2. 在 \(D_{senior}\)（第 4、5、6、10、14 筆）上，算 income、student、credit_rating 的資訊增益，選出最好的屬性。

看解答
\(D_{senior}\)：yes 3、no 2，Info = 0.971。income：medium 3 筆（2/1）、low 2 筆（1/1）→ \(Info_{income}\) = 0.6×0.918 + 0.4×1 = 0.951 → Gain = 0.020。student：no 2 筆（1/1）、yes 3 筆（2/1）→ 0.951 → Gain = 0.020。credit_rating：fair 3 筆全 yes、excellent 2 筆全 no → 0 → Gain = 0.971。選 credit_rating。評分表切到 D_senior 可以驗算。

3. 算 student 的 \(Gini_{student}(D)\) 與 ΔGini。

看解答
student = no：7 筆（yes 3、no 4）→ 1 − (3/7)² − (4/7)² = 0.490；student = yes：7 筆（yes 6、no 1）→ 1 − (6/7)² − (1/7)² = 0.245。\(Gini_{student}(D)\) = 0.5 × 0.490 + 0.5 × 0.245 = 0.367；ΔGini = 0.459 − 0.367 = 0.092。

4. 若有一個屬性把 14 筆資料平均切成 7 個分支（每支 2 筆），它的 SplitInfo 是多少？

看解答
每支比例 1/7：SplitInfo = −7 × (1/7) log₂(1/7) = log₂7 = 2.807。

7.4 情境應用題

1. 你有 1000 筆有標籤的樂器音訊，想比較決策樹和 SVM，並調整樹的最大深度。資料要怎麼切？每份各用在哪一步？

看解答
依講義的比例：先保留 20%（200 筆）當測試集，完全不碰；剩下 800 筆再切 80% 訓練（640 筆）、20% 驗證（160 筆）。用訓練集訓練不同深度的決策樹和不同 C、γ 的 SVM，用驗證集挑出最好的模型與超參數，最後只在測試集上評估一次、回報準確率。

8. 一頁速記

  1. 分類 = 從有標籤的資料學 \(f: X \to Y\)，預測新資料的類別；監督式學習。
  2. 訓練集擬合參數、驗證集選模型與超參數、測試集只做最後評估；講義切法 80/20 再 80/20 → 64/16/20。
  3. 決策樹：內部節點測屬性、分支是結果、葉節點是類別；從根走到葉就是預測。
  4. 建樹：由上而下、遞迴、貪婪；停止於純節點（用該類別）、沒屬性（多數類別）、空分支（父節點的多數類別）。
  5. 熵 \(H = -\sum p \log_2 p\)；純 = 0，兩類別平均 = 1。
  6. \(Gain(A) = Info(D) - \sum \frac{|D_j|}{|D|} Info(D_j)\)，選最大（ID3）。
  7. Gain 偏好分支多；\(GainRatio = Gain / SplitInfo\)，SplitInfo 只看分支筆數（C4.5）。
  8. \(Gini = 1 - \sum p^2\)；純 = 0，兩類別平均 = 0.5；CART 做二元分割、選 ΔGini 最大。
  9. 連續屬性：排序後取相鄰中點當候選門檻；數值屬性可在同一路徑重複使用。
  10. buy_computer：Info(D) = 0.940；Gain：age 0.246 > student 0.151 > credit 0.048 > income 0.029；樹 = age → youth 看 student、middle 直接 yes、senior 看 credit_rating。
