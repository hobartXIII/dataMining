1.1 名詞

1.3 Apriori：Join 與 Prune 的作法

  1. 掃第 1 次：數每個項目 → \(C_1\)，留下計數 ≥ min_sup 的 → \(L_1\)。
  2. Join（連接）：\(L_{k-1}\) 中兩個項目集「前 k − 2 個項目相同、最後一個不同」就合併成一個 k-itemset（項目先照字母排好）。
  3. Prune（剪枝）：檢查每個候選的所有 (k − 1)-子集，只要有一個不在 \(L_{k-1}\)，就刪掉（不用掃資料庫就知道它不頻繁）。
  4. 掃描計數：剩下的候選 \(C_k\) 去資料庫數支持度，≥ min_sup 的成為 \(L_k\)。
  5. 重複 2～4，直到 \(L_k\) 是空的。

範例：9 筆交易、min_sup = 2

  1. \(C_1\)：a 6、b 7、c 6、d 2、e 2、f 1 → f 不頻繁，\(L_1\) = {a, b, c, d, e}
  2. Join：\(L_1\) 兩兩合併得到 10 個 \(C_2\)：ab、ac、ad、ae、bc、bd、be、cd、ce、de（2-itemset 的子集都是 1-itemset，全在 \(L_1\)，不用剪）
  3. 計數：ab 4、ac 4、ad 1、ae 2、bc 4、bd 2、be 2、cd 0、ce 1、de 0 → \(L_2\) = {ab, ac, ae, bc, bd, be}
  4. Join：ab + ac → abc；ab + ae → abe；ac + ae → ace；bc + bd → bcd；bc + be → bce；bd + be → bde（共 6 個） 只有「第一個項目相同」的才能合併，例如 ab 和 bc 不能合併。
  5. Prune：ace 的子集 ce 不在 \(L_2\) → 刪；bcd 的 cd、bce 的 ce、bde 的 de 也不在 → 刪。剩 \(C_3\) = {abc, abe}
  6. 計數：abc 2、abe 2 → \(L_3\) = {abc, abe}
  7. Join：abc + abe → abce；子集 ace、bce 不在 \(L_3\) → 剪掉，\(C_4\) 是空的，結束 頻繁項目集共 13 個：a, b, c, d, e, ab, ac, ae, bc, bd, be, abc, abe。

1.4 Closed 與 Maximal 的判斷法

  • 先列出全部頻繁項目集與計數，再對每一個看它的直接超集合（多一個項目的）。
  • 有超集合計數一樣 → 不是 closed。有超集合是頻繁的 → 不是 maximal。
  • 每個 maximal 一定是 closed，反過來不一定。數量：maximal ≤ closed ≤ frequent。

範例：上面的 13 個頻繁項目集

  1. a:6 的超集合 ab 4、ac 4、ae 2，都比 6 小 → closed；但 ab 是頻繁的 → 不是 maximal
  2. d:2 的超集合 bd:2，計數一樣 → 不是 closed。同理 e:2（ae:2）、ae:2（abe:2）、be:2（abe:2）都不是 closed
  3. bd:2 的超集合 abd 1、bcd 0、bde 0 都不頻繁 → closed 且 maximal
  4. abc:2、abe:2 沒有頻繁的超集合 → closed 且 maximal Closed（9 個）：a, b, c, ab, ac, bc, bd, abc, abe。Maximal（3 個）：bd, abc, abe。

1.5 FP-Growth：Construct FP-tree

  1. 掃第 1 次：數每個項目，刪掉不頻繁的，依計數由大到小排成 F-list（同計數依字母）。
  2. 每筆交易只留頻繁項目，並照 F-list 的順序重排。
  3. 掃第 2 次：從 null 根節點開始，把每筆交易當一條路徑插入：前綴相同就沿用既有節點、計數 +1；不同就開新分支（計數 1）。
  4. 標頭表（header table）用節點鏈（node-link）串起同一個項目的所有節點。

範例：建樹

  1. 計數 b 7、a 6、c 6、d 2、e 2（f 1 刪掉）→ F-list = b, a, c, d, e（a、c 同為 6，依字母）
  2. 重排：001 bae、002 bd、003 bc、004 bad、005 ac、006 bc、007 ac、008 bace、009 bac
  3. 插入後的樹：

1.6 FP-Growth：Mining FP-tree

  1. 從 F-list 最後一個項目開始往前處理。
  2. 沿節點鏈找出該項目的每個節點，往根走得到前綴路徑，計數用該節點的計數 → 條件模式基底（conditional pattern base）。
  3. 在基底中把每個項目的計數加總，刪掉 < min_sup 的 → 建條件 FP-tree。
  4. 條件 FP-tree 中的項目和後綴組合，就是含該後綴的頻繁項目集；樹若還有分支就遞迴。

範例：每個後綴的條件模式基底

  1. e：基底 {b, a}:1、{b, a, c}:1 → 計數 b 2、a 2、c 1 → 留 b, a → 頻繁 e:2、ae:2、be:2、abe:2
  2. d：基底 {b}:1、{b, a}:1 → b 2、a 1 → 留 b → d:2、bd:2
  3. c：基底 {b}:2、{a}:2、{b, a}:2 → b 4、a 4 → 條件樹有兩條分支，遞迴 → c:6、ac:4、bc:4、abc:2
  4. a：基底 {b}:4 → a:6、ab:4
  5. b：基底是空的 → b:7 合起來正好是 Apriori 找到的 13 個頻繁項目集，但只掃了資料庫兩次、沒有產生候選。

1.7 規則評估：Support、Confidence、Lift

$$support(X \Rightarrow Y) = P(X \cup Y) = \frac{count(X \cup Y)}{|D|}, \qquad confidence(X \Rightarrow Y) = \frac{count(X \cup Y)}{count(X)}$$ $$lift(X \Rightarrow Y) = \frac{confidence(X \Rightarrow Y)}{support(Y)} = \frac{P(X \cup Y)}{P(X)P(Y)}$$
  • Lift > 1：正相關（X 出現讓 Y 更可能出現）；= 1：獨立；< 1：負相關。
  • 規則產生：對每個頻繁項目集 l 的每個非空真子集 s，規則 s ⇒ (l − s) 的信賴度 = count(l) / count(s)，≥ min_conf 就輸出。支持度一定夠（因為 l 頻繁）。
  • 注意 \(X \cup Y\) 是「同時包含 X 和 Y 的交易」，不是「含 X 或含 Y」。

範例：從 abe 產生規則（|D| = 9）

  1. count(abe) = 2 → 每條規則的 support = 2/9 = 22.2%
  2. ab ⇒ e：conf = 2/4 = 50%；lift = 0.5 / (2/9) = 2.25（強正相關）
  3. e ⇒ ab：conf = 2/2 = 100%；lift = 1 / (4/9) = 2.25 同一對 X、Y 的 lift 對調前後項不變；信賴度則會變。
  4. 對照：a ⇒ b：conf = 4/6 = 66.7%，看起來不錯，但 lift = (4/6) / (7/9) = 0.857 < 1，其實是負相關 b 本身就出現在 7/9 的交易裡，信賴度 66.7% 反而比「不管 a，b 出現的機率 77.8%」低。這就是只看信賴度的陷阱。

Class label 是什麼：分類資料的每筆物件有一組屬性（特徵）和一個類別標籤；類別標籤也是屬性之一，只是被指定成要預測的目標。例：影像特徵是顏色、形狀、紋理，類別標籤是 Cat 或 Dog。分類是學一個 \(f: X \to Y\)，給沒有標籤的新物件預測它的類別。

2.2 決策樹：怎麼選最好的分割

$$Info(D) = -\sum_i p_i \log_2 p_i, \qquad Info_A(D) = \sum_j \frac{|D_j|}{|D|} Info(D_j), \qquad Gain(A) = Info(D) - Info_A(D)$$ $$SplitInfo_A(D) = -\sum_j \frac{|D_j|}{|D|}\log_2\frac{|D_j|}{|D|}, \qquad GainRatio(A) = \frac{Gain(A)}{SplitInfo_A(D)}$$ $$Gini(D) = 1 - \sum_i p_i^2, \qquad Gini_A(D) = \sum_j \frac{|D_j|}{|D|} Gini(D_j), \qquad \Delta Gini(A) = Gini(D) - Gini_A(D)$$
  1. 算整份資料的 Info(D)（或 Gini(D)）。
  2. 對每個屬性：依屬性值分組，數每組的類別筆數，算每組的熵（或 Gini），再用筆數比例加權平均。
  3. Gain、GainRatio、ΔGini 選最大；\(Info_A\)、\(Gini_A\) 選最小。
  4. 選出的屬性當節點，每個分支遞迴做同樣的事；純節點或沒屬性可用就停。

常用的熵值（背起來省時間）：\(H(1/2, 1/2) = 1\)、\(H(1/4, 3/4) = 0.811\)、\(H(1/3, 2/3) = 0.918\)、\(H(2/5, 3/5) = 0.971\)、\(H(1/5, 4/5) = 0.722\)、\(H(9/14, 5/14) = 0.940\)。

2.3 單純貝氏分類器（Naïve Bayesian）補充

單純貝氏用貝氏定理算每個類別的後驗機率 \(P(C_i \mid X)\)，選最大的類別；「單純」是假設在給定類別下，各屬性彼此條件獨立，所以概似可以拆成每個屬性的乘積。

  • \(P(C_i \mid X) = \frac{P(X \mid C_i)P(C_i)}{P(X)}\)；P(X) 對每個類別都一樣，比大小時可以省略。
  • 條件獨立：\(P(X \mid C_i) = \prod_k P(x_k \mid C_i)\)。
  • 類別屬性：\(P(x_k \mid C_i)\) = 類別 \(C_i\) 中屬性值為 \(x_k\) 的筆數 ÷ 類別 \(C_i\) 的筆數。
  • 零機率問題：只要有一個 \(P(x_k \mid C_i) = 0\)，整個乘積就是 0。用拉普拉斯修正（Laplace correction）：分子 +1、分母 + 該屬性的值數。
  • 補充連續屬性通常假設常態分布：\(P(x_k \mid C_i) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x - \mu)^2}{2\sigma^2}}\)，μ、σ 用該類別的資料算。
$$P(C_i \mid X) \propto P(C_i)\prod_{k=1}^{n} P(x_k \mid C_i), \qquad \text{預測} = \arg\max_i P(C_i)\prod_k P(x_k \mid C_i)$$

範例：用上面 8 筆資料，預測 X = (Outlook = sunny, Wind = weak)

  1. 先驗：P(yes) = 4/8、P(no) = 4/8
  2. yes 類（4 筆）：P(sunny | yes) = 1/4、P(weak | yes) = 4/4
  3. no 類（4 筆）：P(sunny | no) = 3/4、P(weak | no) = 2/4
  4. yes：0.5 × 1/4 × 1 = 0.125；no：0.5 × 3/4 × 2/4 = 0.1875
  5. 0.1875 > 0.125 → 預測 Play = no 若要寫出真正的機率：P(no | X) = 0.1875 / (0.125 + 0.1875) = 0.6。

範例：零機率與拉普拉斯修正，X = (rain, strong)

  1. P(strong | yes) = 0/4 = 0 → yes 的乘積直接變 0，不管其他屬性多支持 yes
  2. 拉普拉斯：Outlook、Wind 各有 2 個值，分母 +2。yes：P(rain | yes) = (3 + 1)/(4 + 2) = 4/6、P(strong | yes) = (0 + 1)/6 = 1/6 → 0.5 × 4/6 × 1/6 = 0.0556
  3. no：P(rain | no) = (1 + 1)/6 = 2/6、P(strong | no) = (2 + 1)/6 = 3/6 → 0.5 × 2/6 × 3/6 = 0.0833
  4. 仍然預測 no，但 yes 不再是 0 教科書的例子：1000 筆中 income = low 0 筆、medium 990、high 10 → 修正後 1/1003、991/1003、11/1003，和原本的比例幾乎一樣。

單純貝氏計算器

選新資料的屬性值，看每個類別的乘積。可以切換資料：8 筆 Play 或教科書的 14 筆 buy_computer（W7 用的同一份）；教科書例子 X = (youth, medium, student = yes, fair) → yes 0.028、no 0.007 → yes。

2.4 支援向量機（SVM）：目標函數

SVM 的目標是在所有能分開兩類的超平面 \(w^Tx + b = 0\) 中，找邊界（margin）\(2/\lVert w \rVert\) 最大的那一個；等價於在 \(y_i(w^Tx_i + b) \ge 1\) 的限制下最小化 \(\lVert w \rVert^2/2\)。

$$\min_{w, b}\ \frac{\lVert w \rVert^2}{2} \quad \text{s.t.}\quad y_i(w^Tx_i + b) \ge 1,\ \ i = 1, \dots, n \qquad (y_i \in \{-1, +1\})$$ $$\text{Soft margin：}\ \min_{w, b, \xi}\ \frac{\lVert w \rVert^2}{2} + C\sum_i \xi_i \quad \text{s.t.}\quad y_i(w^Tx_i + b) \ge 1 - \xi_i,\ \xi_i \ge 0$$
  • 為什麼最小化 \(\lVert w \rVert^2/2\)：邊界 = \(2/\lVert w \rVert\)，最大化它等於最小化 \(\lVert w \rVert\)；取平方、除以 2 是為了好微分。
  • 限制條件的意思：正類要在 \(w^Tx + b \ge 1\) 那側、負類要在 \(\le -1\) 那側，兩條線之間（邊界內）不能有訓練資料。
  • 預測：算 \(f(x) = w^Tx + b\)，≥ 0 → +1、< 0 → −1。
  • C 大 → 違規重罰、邊界窄（容易過度配適）；C 小 → 邊界寬、允許違規。核技巧：\(K(x, z) = \phi(x)^T\phi(z)\)，不用真的轉到高維空間。

範例：給定 w、b，檢查與預測

  1. w = (1, 1)、b = −3 → 決策邊界 \(x_1 + x_2 = 3\)；邊界寬度 = \(2/\sqrt{1^2 + 1^2} = 2/\sqrt{2} = 1.414\)
  2. 訓練點 (1, 1) 標籤 −1：f = 1 + 1 − 3 = −1 → \(y f = 1 \ge 1\) ✓，剛好在邊界上 → 支援向量
  3. 訓練點 (2, 2) 標籤 +1：f = 1 → \(y f = 1\) ✓，也是支援向量
  4. 訓練點 (0, 1) 標籤 −1：f = −2 → \(y f = 2\) ✓，在邊界外
  5. 新資料 (2.2, 0.5)：f = −0.3 < 0 → 預測 −1（落在邊界內，但仍依正負號分類） 只有 (1, 1) 和 (2, 2) 兩點時，最佳邊界就是它們的距離 \(\sqrt{2}\)，所以 \(\lVert w \rVert = \sqrt{2}\)，和 w = (1, 1) 一致。

2.5 集成（Ensemble）：錯誤率怎麼算

n 個彼此獨立、錯誤率都是 ε 的基礎分類器做多數決時，集成會錯 ⇔ 超過一半的分類器同時錯，所以錯誤率是二項分布「錯的個數 ≥ ⌊n/2⌋ + 1」的機率。

$$e_{ensemble} = \sum_{i = \lfloor n/2 \rfloor + 1}^{n} \binom{n}{i}\varepsilon^i(1 - \varepsilon)^{n - i}$$
  • 講義：n = 25、ε = 0.35 → \(\sum_{i=13}^{25}\) … = 0.06。若 25 個預測完全一樣（完全相關），錯誤率還是 0.35。
  • 前提：ε < 0.5 而且分類器之間的錯誤不要高度相關；ε > 0.5 時集成更差。
  • Bagging：取後放回抽 n 筆，每筆被抽到的機率 \(1 - (1 - 1/n)^n \to 0.632\)。Boosting：依序訓練，錯分的樣本權重提高。

範例：n = 3、ε = 0.2

  1. 多數決錯 ⇔ 至少 2 個錯
  2. 剛好 2 個錯：\(\binom{3}{2}0.2^2 \times 0.8 = 3 \times 0.04 \times 0.8 = 0.096\)
  3. 3 個都錯：\(0.2^3 = 0.008\)
  4. \(e_{ensemble}\) = 0.096 + 0.008 = 0.104 < 0.2 n = 5、ε = 0.3 的答案是 0.163（W9 計算題）。可以在 W9 的集成元件驗算任何 n、ε。

3. 評估（Evaluation）

3.1 過度配適（Model Overfitting）

  • 定義：訓練錯誤（training error）很低，但對沒看過的資料泛化很差（test error 高）；模型學到雜訊或偶然樣式。
  • Underfitting：太簡單，訓練、測試錯誤都高。Overfitting：太複雜，訓練錯誤很低、測試錯誤高。
  • 原因：① 訓練資料太少；② 模型太複雜（決策樹太深、太多葉節點）。
  • 選模型：選測試（驗證）錯誤最低的複雜度，不是訓練錯誤最低的。訓練資料變多，兩者差距通常變小。

3.2 混淆矩陣（Confusion Matrix）與指標

Predicted +Predicted −
Actual +TP（真陽性）FN（偽陰性，漏報）
Actual −FP（偽陽性，誤報）TN（真陰性）
$$Accuracy = \frac{TP + TN}{All}, \quad Precision = \frac{TP}{TP + FP}, \quad Recall = Sensitivity = TPR = \frac{TP}{TP + FN}$$ $$Specificity = \frac{TN}{TN + FP}, \quad FPR = \frac{FP}{FP + TN} = 1 - Specificity, \quad F_1 = \frac{2PR}{P + R}, \quad F_\beta = \frac{(1 + \beta^2)PR}{\beta^2 P + R}$$

範例：TP 40、FN 10、FP 20、TN 30（共 100 筆）

  1. Accuracy = (40 + 30)/100 = 70%；Error rate = 30%
  2. Precision = 40/(40 + 20) = 66.7%；Recall = 40/(40 + 10) = 80%
  3. Specificity = 30/(30 + 20) = 60%；FPR = 20/50 = 40%
  4. F1 = 2 × 0.667 × 0.8 / (0.667 + 0.8) = 0.727 講義的癌症練習（TP 90、FN 210、FP 140、TN 9560）：準確率 96.5%，但召回率只有 30%，不平衡資料不能只看準確率。W10 的混淆矩陣元件可以輸入任何數字驗算。

3.3 ROC 曲線（ROC curve）

  1. 依分類器輸出的分數（機率）由高到低排序。
  2. 門檻從最高往下降，每次多把一筆預測為正：真實是 P → 往上走 1/P 格（TPR 增加）；真實是 N → 往右走 1/N 格（FPR 增加）。
  3. 從 (0, 0) 走到 (1, 1)，把每個 (FPR, TPR) 點連起來。
  4. AUC = 曲線下面積：1 完美、0.5 亂猜；越靠左上角越好。

範例：8 筆資料，P 4 筆、N 4 筆

  1. 依分數排序：0.95 P、0.85 P、0.80 N、0.70 P、0.55 N、0.45 P、0.40 N、0.30 N
  2. 點依序：(0, 0) → (0, 0.25) → (0, 0.5) → (0.25, 0.5) → (0.25, 0.75) → (0.5, 0.75) → (0.5, 1) → (0.75, 1) → (1, 1)
  3. AUC：把每一段往右走的地方當長方形加總：0.25 × 0.5 + 0.25 × 0.75 + 0.25 × 1 + 0.25 × 1 = 0.125 + 0.1875 + 0.25 + 0.25 = 0.8125
  4. 例如門檻 0.70（前 4 筆預測為正）：TP 3、FP 1 → TPR 0.75、FPR 0.25 補充AUC 也等於「隨機抽一個正例、一個負例，正例分數比較高的機率」：16 對中有 13 對正例在前 → 13/16 = 0.8125。

4.2 K-means：作法、性質與限制

  1. 選 K 個初始中心（centroid）。
  2. 分配：每個點分給最近的中心。
  3. 更新：每群的中心改成群內點的平均。
  4. 重複 2～3，直到沒有點換群。
性質（Properties）限制（Limitations）
簡單、相對有效率：O(nKdt)要事先指定 K（用手肘法或輪廓係數挑）
每一步都讓 SSE 不增加，一定會收斂常收斂到區域最小值，結果受初始中心影響（K-means++ 改善）
目標：最小化 \(SSE = \sum_k\sum_{x \in C_k}\lVert x - c_k \rVert^2\)對雜訊、離群值敏感（平均會被拉走；K-medoids 較穩健）
每群用平均當代表（不一定是真實點）群的大小、密度差很多時表現差；找不出非凸（non-convex）的群
只能用在可以算平均的數值資料（類別資料用 K-modes）

範例：一維資料 2, 4, 10, 11, 12, 20, 25, 30，K = 2，初始中心 2、4

  1. 第 1 輪：只有 2 離 2 比較近 → {2} | {4, 10, 11, 12, 20, 25, 30} → 中心 2、112/7 = 16
  2. 第 2 輪：4 到 2 是 2、到 16 是 12 → 去左邊；10 到 2 是 8、到 16 是 6 → 右邊 → {2, 4} | {10, …, 30} → 中心 3、108/6 = 18
  3. 第 3 輪：10 到 3 是 7、到 18 是 8 → 左；11 到 3 是 8、到 18 是 7 → 右 → {2, 4, 10} | {11, 12, 20, 25, 30} → 中心 5.33、19.6
  4. 第 4 輪：11（5.67 vs. 8.6）、12（6.67 vs. 7.6）都去左 → {2, 4, 10, 11, 12} | {20, 25, 30} → 中心 7.8、25
  5. 第 5 輪：沒有點換群 → 收斂。SSE = (5.8² + 3.8² + 2.2² + 3.2² + 4.2²) + (5² + 0 + 5²) = 80.8 + 50 = 130.8 考試時每一輪都要寫出「分配結果」和「新中心」。W11 的遊樂場可以看二維版本。

4.3 階層式分群：凝聚式（Bottom-up / Agglomerative）與連結

  1. 每個點自成一群，寫出鄰近度（距離）矩陣。
  2. 找矩陣中最小的一格，合併那兩群，記下合併的高度（距離）。
  3. 依連結準則（linkage）更新合併後那一群到其他群的距離。
  4. 重複到只剩一群；畫成樹狀圖（dendrogram），切在某個高度得到分群。
Linkage新距離怎麼算特性
Single（MIN）兩群之間最近的一對點容易鏈結（chaining）
Complete（MAX）兩群之間最遠的一對點偏好緊密的群
Average（group average）所有跨群點對距離的平均介於兩者之間
Centroid兩群中心點的距離需要座標
Ward合併後 SSE 的增加量選增加最少的

範例：講義 W11 第 70 頁的 5 點矩陣

  1. d12 = 2.3、d13 = 3.4、d14 = 1.2、d15 = 3.7、d23 = 2.0、d24 = 1.8、d25 = 2.2、d34 = 4.2、d35 = 0.7、d45 = 4.4
  2. 兩種連結的前兩步一樣：0.7 合併 {3, 5}、1.2 合併 {1, 4}
  3. Single：d({1,4}, 2) = min(2.3, 1.8) = 1.8、d({3,5}, 2) = min(2.0, 2.2) = 2.0、d({1,4}, {3,5}) = 3.4 → 1.8 合併 {1, 2, 4} → 2.0 全部合併
  4. Complete：d({1,4}, 2) = max = 2.3、d({3,5}, 2) = 2.2、d({1,4}, {3,5}) = 4.4 → 2.2 合併 {2, 3, 5} → 4.4 全部合併 同一個矩陣、不同連結 → 不同的兩群：single {1, 2, 4} | {3, 5}；complete {1, 4} | {2, 3, 5}。W11 的元件可以逐步看矩陣更新。

4.4 DBSCAN：點的種類（Types of points）補充

DBSCAN 用兩個參數 ε（Eps，鄰域半徑）和 MinPts，把每個點分成核心點、邊界點、雜訊點；彼此密度可達的核心點和它們的邊界點組成一群，雜訊不屬於任何群。

  • Core point（核心點）：ε 鄰域內（含自己）至少有 MinPts 個點。
  • Border point（邊界點）：自己不是核心點，但落在某個核心點的 ε 鄰域內。
  • Noise point（雜訊點／離群點）：既不是核心點也不是邊界點。
  • 直接密度可達（directly density-reachable）：q 是核心點、p 在 q 的 ε 鄰域內。密度可達：一串直接密度可達串起來。密度相連：兩點都從同一個點密度可達。
  • 優點：不用給 K、能找任意形狀的群、能標出雜訊。缺點：對 ε、MinPts 敏感；群的密度差很多時很難調。
  • 注意：有些課本的 MinPts 不含點本身，考試時看題目定義。

範例：A(1,1)、B(1,2)、C(2,1)、D(2,2)、E(3,2)、F(4,2)、G(7,6)，ε = 1.5、MinPts = 4（含自己）

  1. 算每點 ε 鄰域：A {A, B, C, D}（A–D 距離 \(\sqrt{2}\) = 1.414 ≤ 1.5）、B {A, B, C, D}、C {A, B, C, D, E}、D {A, B, C, D, E}、E {C, D, E, F}、F {E, F}、G {G}
  2. 鄰域 ≥ 4 個 → 核心點：A、B、C、D、E
  3. F 只有 2 個 → 不是核心；但它在核心點 E 的鄰域內 → 邊界點
  4. G 只有自己，也不在任何核心點的鄰域內 → 雜訊點
  5. A～E 的核心點彼此直接密度可達，加上邊界點 F → 一群 {A, B, C, D, E, F}；G 是雜訊
