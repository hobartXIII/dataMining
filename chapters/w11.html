🫧 分群

分群（Clustering）是把一組資料物件分成好幾群，讓同一群內的物件彼此相似、不同群的物件彼此不相似；它不需要類別標籤，是非監督式學習。

  • 「相似」取決於資料怎麼表示、用哪種相似度或距離；同一份資料可以有好幾種合理的分法，沒有放諸四海皆準的最佳分群。
  • 不同屬性類型用不同的相異度：名目看不相符比例、二元分對稱與非對稱、數值用 Minkowski 距離、順序先轉成 [0, 1] 的排名、混合型用 Gower 距離。
  • 四大方法：分割式（K-means、K-medoids）、階層式（凝聚、分裂）、密度式、模型式。
  • K-means 要先給 K、對初始值和離群值敏感、找不出非凸的群；K-means++ 改善初始化，K-medoids 用真實資料點當代表、比較耐離群值。

1. 本章摘要

  • 分群又叫群集分析（cluster analysis）或資料分割（data segmentation）。用途：發現隱藏的結構、用少數幾群摘要大量資料、支援後續分析（顧客分群與推薦、分類的前處理、離群值偵測）。
  • 好的分群：群內相似度高（cohesive）、群間相似度低（well separated）。群的定義有四種：分離良好、原型式、連續性（連通）、密度式。
  • 輸入有兩種形式：資料矩陣（n 個物件 × p 個屬性，two-mode）與相異度矩陣（n × n，one-mode）。
  • K-means：選 K 個中心 → 每點分給最近的中心 → 重算中心（平均）→ 重複到沒有點換群。複雜度 O(nKdt)，常收斂到 SSE 的區域最小值。
  • 階層式分群建出巢狀的群，切在某一層得到最後結果；凝聚式（由下而上）每次合併最近的兩群，群間距離由連結準則決定：單一、完全、平均、中心、Ward。

2. 核心概念

2.1 分群演算法應有的特性（第 5～8 頁）

  1. 能處理不同資料類型：二元、類別、順序、數值、文字、圖、序列、影像、影片。
  2. 可擴展性（Scalability）：能有效處理大型資料集。
  3. 能找出任意形狀的群，不只是緊密的球形群。
  4. 對雜訊與離群值穩健（robust）。
  5. 盡量少依賴領域知識與使用者給的參數，例如最好不用事先知道群數。
  6. 可漸進式分群、對輸入順序不敏感：新資料進來不用整個重算。
  7. 能處理高維資料。
  8. 支援使用者限制，例如兩個物件必須同群（must-link）或不能同群（cannot-link）。
  9. 可解釋、可用：結果要看得懂、能拿來行動。

2.2 分群可能有歧義（第 9～13 頁）

  • 同一份資料可以合理地分成 2 群、4 群或 6 群：某個細節層級有用的分法，換一個層級不一定有用。
  • 不同的相似度量度會得到不同的群。最終標準是：分群結果對想做的任務有沒有用。
  • 音樂例子：《給愛麗絲》的自我相似矩陣（Self-Similarity Matrix）可以把曲子切成好幾段，相似的段落會重複出現。

2.3 四種「群」的觀念（第 15～19 頁）

觀念定義特性
① 分離良好（Well-separated）群內每一點和群內任一點，都比和群外任何點更相似適合緊密、分得很開的群；描述不了細長或交纏的群
② 原型式（Prototype-based）每個物件分給最近（最相似）的原型所屬的群原型可以是中心點（centroid，所有點的平均，不一定是真實資料點）或代表點（medoid，到群內其他點總距離最小的真實資料點）
③ 連續性（Contiguity-based）群是一串由「鄰近」點連起來的點，又叫連通式群內的點不必彼此都很近；群可以是任意的連通形狀
④ 密度式（Density-based）群是密集的區域，被低密度區域和其他密集區域隔開可找任意形狀、能把稀疏的點當雜訊

分群品質取決於：資料表示與相似度量度、演算法採用的群定義、演算法的假設與參數，以及找到的結構對任務有沒有用。應用：生物（物種分群、生物亞型）、資訊檢索（相似文件）、遙測（土地利用）、行銷（顧客分群）、地震研究（震央的空間樣式揭露斷層）。

2.4 資料矩陣與相異度矩陣（第 24～25 頁）

資料矩陣是 n 個物件 × p 個屬性的表（物件對屬性，two-mode）；相異度矩陣是 n × n 的表，第 (i, j) 格是物件 i 和 j 的相異度 d(i, j)（物件對物件，one-mode）。

  • 相異度矩陣對稱、對角線是 0，所以通常只寫下三角。
  • 屬性類型：名目（紅、綠、藍）、二元（正面、反面）、數值（重量、身高）、順序（大一、大二、大三、大四）。

2.5 各種屬性的相異度（第 27～34 頁）

  • 名目：\(d(i, j) = (p - m)/p\)，p 是變數數，m 是相符的變數數。
  • 對稱二元（兩個狀態一樣重要，例：正反面）：\(d = (r + s)/(q + r + s + t)\)。
  • 非對稱二元（兩個狀態不一樣重要，例：有沒有生病）：\(d = (r + s)/(q + r + s)\)，忽略「兩邊都是 0」的 t。
  • 數值：歐氏（L2）、曼哈頓（L1）、Minkowski（\(L_h\)）、加權 Minkowski、上確界（Chebyshev、\(L_\infty\)）。
  • 順序：把值換成排名 \(r_{if} \in \{1, \dots, M_f\}\)，再映射到 [0, 1]：\(z_{if} = (r_{if} - 1)/(M_f - 1)\)，然後當數值算。例：大一 0、大二 1/3、大三 2/3、大四 1。
  • 混合型：Gower 距離，每個屬性先算正規化的相異度，再加權平均。

3. 演算法與方法

3.1 四大分群方法（第 36 頁）

方法做法例子
① 分割式（Partitioning）反覆形成或修正一個分割，讓某個準則（例：SSE）最佳K-means、K-medoids
② 階層式（Hierarchical）依某個準則建立資料的階層式分解凝聚式（AGNES）、分裂式、Bisecting K-means
③ 密度式（Density-based）依連通性與密度函數補充DBSCAN、OPTICS
④ 模型式（Model-based）假設每一群有一個模型，讓模型去配適資料補充高斯混合模型（EM 演算法）

3.2 分割式方法與 K-means（第 38～47 頁）

分割式方法把 n 個物件的資料庫 D 分成 K 群，讓目標函數最佳，例如每點到所屬群代表（中心或代表點）的距離平方和 SSE 最小；K-means 用群的平均當代表。

  • 全域最佳要列舉所有可能的分割，很快就不可行，所以用啟發式、反覆改進的方法。
  • K-means（Lloyd 演算法，1957 提出、1982 發表）：要先指定 K，每群有一個中心，每點分給最近的中心。
  • 步驟：① 選 K 個初始中心 → ② 重新分配：每點分給最近的中心 → ③ 更新中心：用目前分割算每群的平均 → ④ 重複 ②③ 直到沒有點換群。
  • 標準 K-means 用歐氏距離、用平均更新中心。
  • 效率：O(nKdt)，n 物件數、K 群數、d 維度、t 迭代次數，算相對有效率。
  • 常收斂到 SSE 的區域最小值：初始中心不同，結果可能不同（講義第 45 頁：另一組隨機初始中心收斂到 SSE 較高的解）。實務上換不同初始值多跑幾次。
  • 要事先指定 K：實務上試一個範圍的 K，再用手肘法（elbow method）或輪廓係數（silhouette score）挑。
  • 對雜訊和離群值敏感（離群值會把平均拉走）；群的大小或密度差很多時表現差；找不出非凸（non-convex）的群。

3.3 K-means 的變形（第 51～58 頁）

K-means++ 改善初始化：第一個中心隨機選，之後每個點被選為下一個中心的機率和 \(D(x)^2\) 成正比，\(D(x)\) 是它到最近已選中心的距離；離現有中心越遠越容易被選到。

  • 重複直到選出 K 個初始中心，接著照一般 K-means 跑（〈k-means++: The Advantages of Careful Seeding〉，SODA 2007）。
變形群的代表特點
K-medoids群內真實存在的一個資料點（medoid）medoid 讓到群內其他點的總相異度最小；比較耐離群值
K-medians每一維各自取中位數用 L1（曼哈頓）距離；中位數比平均不受極端值影響
K-modes每個屬性取眾數處理類別資料（K-means 不能處理非數值）；相異度用不相符的屬性數

3.4 K-medoids：PAM 與 CLARA（第 54～57 頁）

  1. PAM（Partitioning Around Medoids）：a. BUILD：選 K 個初始 medoid；b. 每個物件分給最近的 medoid；c. SWAP：評估每個 medoid 和每個非 medoid 交換的效果；d. 執行讓總成本下降最多的交換；e. 重複到沒有交換能降低成本。
  2. 講義第 56 頁的例子：K = 2，總成本 20 時嘗試一個交換得到 26，成本變高 → 拒絕交換。
  3. PAM 對小資料有效，但每輪要評估 K(n − K) 種交換，不適合大資料。
  4. CLARA（Clustering LARge Applications，類似 Apriori 的抽樣法）：① 從全資料隨機抽幾份可處理大小的樣本；② 每份樣本跑 PAM 得到一組候選 medoid；③ 每組候選都把全資料分給最近的 medoid、算總相異度；④ 選全資料成本最低的那組。

3.5 階層式分群（第 60～75 頁）

階層式分群建出巢狀的群（樹狀圖，dendrogram），再選一個切割高度得到最後的分群；不用事先選 K，但合併或分裂一旦做了就不能反悔。

  • 凝聚式（Agglomerative，由下而上，比較常用）：每個物件自成一群 → 算鄰近度矩陣 → 重複「合併最近的兩群、更新鄰近度矩陣」直到剩一群。
  • 分裂式（Divisive，由上而下）：全部在同一群，遞迴地切成更小的群。要決定：下一個切哪一群、怎麼切、怎麼評估候選切法；達到停止條件（例：目標群數）就停。
  • 和 K-means 不同：不會反覆重新分配物件。
連結準則兩群的距離特性
單一連結（MIN）跨群最近的一對點看局部連接，可能沿著一串鄰近點把兩群連起來（鏈結效應）
完全連結（MAX）跨群最遠的一對點偏好緊密的群
平均連結（Group average）所有跨群點對距離的平均介於兩者之間
中心連結（Centroid）兩群中心點的距離需要座標
Ward 連結合併後群內 SSE 的增加量 ΔSSE選 ΔSSE 最小的一對合併

凝聚式階層分群：單一 vs. 完全連結

講義第 70 頁的 5 點鄰近度矩陣。每一步找出矩陣中最小的一格（框起來）合併，再依連結準則更新合併後那一列。單一和完全連結前兩步一樣（{3, 5}、{1, 4}），第三步開始不同。

3.6 Bisecting K-means 與講義之後的內容

  • Bisecting K-means（〈A comparison of document clustering techniques〉，KDD workshop 2000）：要得到 K 群，就反覆把某一群用 2-means 切成兩群，直到有 K 群為止。

待確認講義文字只擷取到第 76 頁 Bisecting K-means 的第一句（「Select one of these clus…」），之後的內容（可能包括 Bisecting 的細節、密度式與模型式方法、分群品質評估）沒擷取到。以下是 補充依教科書整理的重點，請對照原始投影片。

  • 補充Bisecting K-means：每輪挑一群（通常是 SSE 最大或最大的群）切開，試幾次 2-means、留 SSE 最小的切法。
  • 補充DBSCAN：參數 ε（鄰域半徑）與 MinPts。ε 鄰域內至少有 MinPts 個點（含自己）的是核心點；在核心點鄰域內但自己不是核心的是邊界點；其餘是雜訊。彼此可達的核心點和它們的邊界點組成一群。可找任意形狀、不用給 K、會標出雜訊，但對 ε、MinPts 敏感，密度差很多時難調。
  • 補充模型式：例如高斯混合模型（GMM），假設資料由 K 個高斯分布混合而成，用 EM 演算法交替做 E 步（算每點屬於各群的機率，軟分配）與 M 步（更新各高斯的參數）。
  • 補充評估分群：手肘法（畫 K 對 SSE，找下降變緩的轉折點）；輪廓係數 \(s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}\)，a 是到同群其他點的平均距離、b 是到最近的別群的平均距離，介於 −1 和 1，越接近 1 越好。

4. 公式整理

4.1 名目與二元（第 27～28 頁）

$$d(i, j) = \frac{p - m}{p}, \qquad d_{sym}(i, j) = \frac{r + s}{q + r + s + t}, \qquad d_{asym}(i, j) = \frac{r + s}{q + r + s}$$

q：i、j 都是 1；r：i 是 1、j 是 0；s：i 是 0、j 是 1；t：都是 0。

4.2 數值（第 30 頁）

$$d(i, j) = \sqrt[h]{|x_{i1} - x_{j1}|^h + |x_{i2} - x_{j2}|^h + \cdots + |x_{ip} - x_{jp}|^h}$$ $$h = 1:\ \text{曼哈頓}, \qquad h = 2:\ \text{歐氏}, \qquad h \to \infty:\ d(i, j) = \max_f |x_{if} - x_{jf}|$$ $$\text{加權：} d(i, j) = \sqrt[h]{w_1|x_{i1} - x_{j1}|^h + \cdots + w_p|x_{ip} - x_{jp}|^h}$$

4.3 順序與混合型（第 32～34 頁）

$$z_{if} = \frac{r_{if} - 1}{M_f - 1}, \qquad d(i, j) = \frac{\sum_f w_f\, d_{ij}^{(f)}}{\sum_f w_f}$$

數值屬性的 \(d_{ij}^{(f)} = \frac{|x_{if} - x_{jf}|}{\max_h x_{hf} - \min_h x_{hf}}\)（補充依教科書：用該屬性的全距正規化）。

4.4 分割式的目標函數（第 38 頁）

$$SSE = \sum_{k=1}^{K} \sum_{x_i \in C_k} \lVert x_i - c_k \rVert^2$$

4.5 連結準則（第 68～73 頁）

$$D_{single}(C_i, C_j) = \min_{p \in C_i,\, p' \in C_j} d(p, p'), \qquad D_{complete}(C_i, C_j) = \max_{p \in C_i,\, p' \in C_j} d(p, p')$$ $$D_{avg}(C_i, C_j) = \frac{1}{|C_i||C_j|}\sum_{p \in C_i}\sum_{p' \in C_j} d(p, p'), \qquad D_{centroid}(C_i, C_j) = \lVert c_i - c_j \rVert$$ $$\Delta SSE(C_i, C_j) = SSE(C_i \cup C_j) - SSE(C_i) - SSE(C_j)$$

5. 範例演算

例一：非對稱二元相異度（第 29 頁）

  1. Jack = 1 0 1 0 0 0、Mary = 1 0 1 0 1 0、Jim = 1 1 0 0 0 0（發燒、咳嗽、test-1～4）
  2. d(Jack, Mary)：q = 2（發燒、test-1）、r = 0、s = 1（test-3）→ (0 + 1)/(2 + 0 + 1) = 0.33
  3. d(Jack, Jim)：q = 1、r = 1（test-1）、s = 1（咳嗽）→ (1 + 1)/(1 + 1 + 1) = 0.67
  4. d(Jim, Mary)：q = 1、r = 1（咳嗽）、s = 2（test-1、test-3）→ (1 + 2)/(1 + 1 + 2) = 0.75 Jack 和 Mary 最可能得同一種病；Jim 和 Mary 最不像。

例二：順序屬性與 Gower 距離（第 33～34 頁）

  1. test-2 有三個狀態 fair < good < excellent，\(M_f = 3\)：排名 1 → (1 − 1)/2 = 0、排名 2 → 0.5、排名 3 → 1
  2. 物件 1 = (A, excellent, 45)、物件 2 = (B, fair, 22)
  3. test-1 名目：A ≠ B → 1；test-2 順序：|1 − 0| = 1；test-3 數值：|45 − 22| / (64 − 22) = 23/42 ≈ 0.548
  4. \(d(1, 2) = (1 + 1 + 0.548)/3 \approx 0.849\) 三個屬性權重都是 1。上面的混合型元件可以驗算整個矩陣。

例三：單一連結（第 70 頁）

  1. 最小的是 d(3, 5) = 0.7 → 合併 {3, 5}
  2. 更新：d({3,5}, 1) = min(3.4, 3.7) = 3.4、d({3,5}, 2) = min(2.0, 2.2) = 2.0、d({3,5}, 4) = min(4.2, 4.4) = 4.2
  3. 最小的是 d(1, 4) = 1.2 → 合併 {1, 4}；d({1,4}, 2) = min(2.3, 1.8) = 1.8、d({1,4}, {3,5}) = 3.4
  4. 最小的是 1.8 → 合併 {1, 2, 4}；d({1,2,4}, {3,5}) = min(3.4, 2.0) = 2.0
  5. 最後在 2.0 合併成一群

例四：完全連結（第 70 頁）

  1. 前兩步一樣：0.7 合併 {3, 5}，1.2 合併 {1, 4}
  2. 更新用最大值：d({1,4}, 2) = max(2.3, 1.8) = 2.3、d({3,5}, 2) = max(2.0, 2.2) = 2.2、d({1,4}, {3,5}) = max(3.4, 3.7, 4.2, 4.4) = 4.4
  3. 最小的是 2.2 → 合併 {2, 3, 5}（單一連結是 2 併到 {1, 4}）
  4. 最後在 4.4 合併成一群 同一個矩陣，換連結準則就得到不同的兩群：單一 {1, 2, 4} | {3, 5}、完全 {1, 4} | {2, 3, 5}。

7. 複習問題

7.1 選擇題

1. 兩點 (1, 2) 和 (3, 5) 的上確界（\(L_\infty\)）距離是多少？

(B)。兩維的差分別是 2 和 3，取最大值 3。(C) 是歐氏、(D) 是曼哈頓。

2. 下列哪一種情況 K-means 最可能表現不好？

(C)。K-means 依「離哪個中心近」分群，邊界是直線（Voronoi），找不出非凸的群。可以在遊樂場選「月牙形」看看，再切到 DBSCAN 比較。

3. 計算兩位病人在「有沒有某些症狀」上的相異度時，為什麼用非對稱二元？

(A)。大部分症狀大家都沒有，如果把 t（都是 0）算進分母，每個人都會顯得很像。

4. K-means++ 選下一個初始中心的機率和什麼成正比？

(D)。離現有中心越遠的點越可能被選，初始中心因此分散開來。

7.2 觀念題

1. 為什麼 K-means 一定會收斂，卻不一定找到最好的分群？

看解答
分配步驟（每點去最近的中心）和更新步驟（中心換成平均）都不會讓 SSE 變大，而分割的可能數有限，所以一定會停。但它只是沿著 SSE 往下走，停在哪裡取決於初始中心，常常是區域最小值；所以要換不同初始值多跑幾次，或用 K-means++。

2. K-medoids 為什麼比 K-means 不怕離群值？代價是什麼？

看解答
平均會被極端值拉走，而 medoid 必須是群內的真實資料點，而且是讓總相異度最小的那一個，一個離群值很難讓它移動。代價是計算量：PAM 每輪要試 K(n − K) 種交換、每種都要重算成本，大資料要改用 CLARA 抽樣。

3. 單一連結的「鏈結效應」是什麼？

看解答
單一連結只看跨群最近的一對點，只要兩群之間有一串彼此相鄰的點（像一座橋），兩群就會很早被併在一起，形成又細又長的群。好處是能找出非橢圓形的群，壞處是對雜訊形成的「橋」很敏感。

7.3 計算題

1. 順序屬性「年級」有大一～大四四個狀態，大二和大四的相異度是多少？

看解答
\(M_f = 4\)：大二 → (2 − 1)/3 = 1/3、大四 → (4 − 1)/3 = 1，相異度 |1/3 − 1| = 2/3 ≈ 0.667。

2. 一維資料 1, 2, 3, 10, 11, 12，K = 2，初始中心 1 和 2。跑 K-means 直到收斂，最後的中心和 SSE 是多少？

看解答
第 1 輪分配：{1} 和 {2, 3, 10, 11, 12} → 中心 1、7.6。第 2 輪：1、2、3 離 1 比較近（3 到 1 是 2、到 7.6 是 4.6），10、11、12 去 7.6 → {1, 2, 3}、{10, 11, 12} → 中心 2、11。第 3 輪不變，收斂。SSE = (1 + 0 + 1) + (1 + 0 + 1) = 4。

3. 用講義第 70 頁的矩陣做平均連結，前三步分別合併哪些群、在什麼高度？

看解答
① 0.7 合併 {3, 5}；② 1.2 合併 {1, 4}；③ d({1,4}, 2) = (2.3 + 1.8)/2 = 2.05、d({3,5}, 2) = (2.0 + 2.2)/2 = 2.1、d({1,4}, {3,5}) = (3.4 + 3.7 + 4.2 + 4.4)/4 = 3.925 → 2.05 合併 {1, 2, 4}；最後 d({1,2,4}, {3,5}) = (3.4 + 3.7 + 2.0 + 2.2 + 4.2 + 4.4)/6 = 3.317。元件選「平均」可以驗算。

7.4 情境應用題

1. 電商想把 50 萬名顧客分群做行銷，資料有年齡、年消費金額（數值）、會員等級（銅／銀／金）、居住縣市（名目）。你會怎麼處理相異度與選演算法？

看解答
屬性是混合型：數值先正規化（否則消費金額主導），會員等級當順序屬性轉成 0、0.5、1，縣市當名目（相同 0、不同 1），用 Gower 距離合併。50 萬筆用 PAM 太慢，可用 CLARA 抽樣，或把類別 one-hot 後用 K-means／K-prototypes；K 用手肘法或輪廓係數在幾個候選值中挑，最後還要看各群能不能解釋、能不能做成行銷方案。

8. 一頁速記

  1. 分群：群內相似、群間不相似；非監督式；沒有放諸四海皆準的最佳解，看任務有沒有用。
  2. 群的四種觀念：分離良好、原型式（centroid／medoid）、連續性（連通）、密度式。
  3. 資料矩陣 n × p（two-mode）；相異度矩陣 n × n（one-mode，對稱、對角線 0）。
  4. 名目 (p − m)/p；對稱二元 (r + s)/(q + r + s + t)；非對稱二元 (r + s)/(q + r + s)。
  5. Minkowski：h = 1 曼哈頓、2 歐氏、∞ 上確界。順序：\(z = (r - 1)/(M - 1)\)。混合：Gower 加權平均（講義例 0.849）。
  6. 四大方法：分割式、階層式、密度式、模型式。
  7. K-means：初始中心 → 分配 → 更新平均 → 直到不變；O(nKdt)；區域最小值、要給 K、怕離群值、找不到非凸群。
  8. K-means++：下一個中心的機率 ∝ \(D(x)^2\)。K-medoids（PAM：BUILD + SWAP；CLARA：抽樣）、K-medians（中位數、L1）、K-modes（眾數、類別）。
  9. 階層式：凝聚（常用）／分裂；不用給 K、合併不能反悔；連結：單一 min、完全 max、平均、中心、Ward（ΔSSE）。
  10. 講義矩陣：單一連結 → {1,2,4} | {3,5}（2.0）；完全連結 → {1,4} | {2,3,5}（4.4）。
