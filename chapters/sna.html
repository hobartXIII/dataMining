🕸️ 社群網路探勘

社群網路把社會行動者（人、組織、帳號）當成節點、把他們之間的關係（友誼、溝通、合作、信任）當成邊，表示成圖 G = (V, E)；社群網路探勘從網路結構與屬性中找出有用的樣式並建立預測模型。

  • 四大任務：① 中心性分析（誰的位置重要）；② 社群偵測（哪些節點自成一群）；③ 連結預測（哪些邊會出現）；④ 資訊擴散（訊息怎麼傳開）。
  • 四種中心性：度（直接連結多）、介數（在很多最短路徑上）、接近（到其他人平均距離短）、特徵向量（連到重要的人）。
  • 好的社群分法：群內邊多、群間邊少；模組度 Q 衡量「群內邊比隨機期望多多少」。
  • 擴散模型：線性門檻模型（LTM）看鄰居影響力總和、獨立串聯模型（ICM）每條邊只有一次機會；傳染病模型 SI、SIR、SIS、SIRS。

1. 本章摘要

  • 邊可以是有向或無向（追蹤 vs. 互為好友）、加權或不加權（溝通頻率 vs. 有沒有連結）。即使是小團體，關係網也可能很複雜（講義引用 1981 年 Peanuts 漫畫）。
  • 中心性：不同量度可能把同一批節點排出不同順序，「重要」取決於想量什麼；結構上重要不一定等於實際有影響力。
  • 社群偵測和分群的差別：分群看物件的特徵相似度，社群偵測看連結樣式；可以把社群偵測看成以網路結構為依據的分群。方法分成員式（clique 及其放寬）與群體式（圖分割、模組度最大化）。
  • 連結預測：同質性（相似的人會連在一起）與三元閉包（有共同朋友的人會變朋友）→ 用共同鄰居、Jaccard、Adamic–Adar、偏好連結打分數排序，或用這些分數當特徵訓練分類器、用 GNN 學節點表示。
  • 資訊擴散：漸進式模型（啟動後一直保持啟動）有 LTM、ICM；影響力最大化是在預算 k 下選種子集合讓期望擴散 σ(S) 最大；傳染病模型允許康復或再次易感。

2. 核心概念

2.1 為什麼中心性重要（第 8～11 頁）

  • 少數法則（The Law of the Few，Malcolm Gladwell《引爆趨勢》）：少數行動者在訊息傳播上扮演不成比例的角色。
  • 三種社會角色：連結者（Connectors，認識不同圈子的很多人，幫訊息跨群傳遞）、專家（Mavens，蒐集、評估某領域的資訊並樂於分享）、推銷員（Salesmen，有說服力，讓別人採取行動）。這些角色可以重疊；中心性量度只看網路位置。
  • 網路位置的差別：有人直接連結很多、有人是不同群之間的橋、有人能用很短的路徑到達其他人。

2.2 四種中心性（第 12～23 頁）

「重要」的意思中心性定義
直接連結最多度中心性（Degree）直接連結的數量
在很多最短路徑上介數中心性（Betweenness）所有節點對之間的最短路徑中，經過該節點的比例總和
到其他節點的平均距離短接近中心性（Closeness）到其他節點最短距離的平均的倒數
連到其他重要的節點特徵向量中心性（Eigenvector）鄰居的中心性越高，自己越高
  • 度：鄰居越多、直接接觸越多、潛在影響越大。正規化：除以 n − 1（簡單無向圖中一個節點最多連 n − 1 個）。限制：只看局部，鄰居多不代表能到達網路的其他部分。
  • 介數：當橋梁或掮客（broker）、控制資訊流、連接網路的不同部分；度可能很低但戰略地位很高。每個節點對的功勞平均分給它的各條最短路徑。
  • 接近：全域可及性；靠最短路徑傳訊時溝通有效率。接近度看的是圖上的距離，不是畫出來的位置。
  • 特徵向量：「不只看你有多少朋友，還看你的朋友是誰」；鄰居少但鄰居都很重要的節點，分數可能更高。

2.3 社群結構與社群偵測（第 26～29 頁）

社群結構是一群內部連結相對密集、對外連結相對稀疏的節點；社群偵測就是從網路的連結樣式找出這些群。

  • 真實網路常有社群結構：朋友網路（家人、同學、實驗室、遊戲朋友）、引用網路（論文多半引用相關領域，例如機器學習和生物）。
  • 不是所有網路都有明顯的社群結構；社群可能重疊，或存在於不同尺度。

2.4 成員式社群偵測（第 30～36 頁）

clique（團）是兩兩之間都直接相連的節點集合；n 個節點的 clique 有 n(n − 1)/2 條邊，它和外部節點的連結不受限制。成員式方法用 clique 和它的各種放寬版本，對成員加上結構限制。

  • 最大 clique（maximum）：圖中節點最多的 clique。極大 clique（maximal）：不能再加入任何節點的 clique。每個最大 clique 都是極大的，反之不一定。
  • 找最大 clique 是 NP-hard；極大 clique 的數量可能是節點數的指數。
  • 度剪枝：找大小 k 的 clique 時，反覆刪掉在剩下的圖中度數 < k − 1 的節點。度數 ≥ k − 1 是必要條件，但不是充分條件。

2.5 群體式社群偵測（第 37～42 頁）

  • 依群體層級的準則評估分法：平衡（各群大小相近）、穩健（移除一些節點或邊後仍連通）、模組化（內密外疏）、密集（內部邊密度高）、階層（多個尺度都有社群）。不同方法強調不同準則，社群不必全部滿足。
  • Kernighan–Lin（KL）：把 2n 個節點的圖分成兩群各 n 個（平衡），讓群間連結最少；是一種啟發式，靠交換兩群的節點來改善。
  • Girvan–Newman（GN）：連接不同社群的橋梁邊通常有很高的邊介數。① 算邊介數 → ② 移除介數最高的邊 → ③ 在剩下的圖重算 → ④ 重複，得到分法的階層；再用模組度等準則選一層。

模組度（Modularity）Q 衡量一個分法捕捉社群結構的程度：觀察到的群內邊比例，減去在隨機（保留度數的虛無模型）下期望的群內邊比例。

  • 節點 i、j 之間期望的邊數 \(= k_i k_j / 2m\)（k 是度數、m 是邊數）。
  • Q ≈ 0：和虛無模型的期望差不多；Q > 0：群內邊比期望多。比較同一張圖的不同分法時，Q 越高越好。

模組度與 Girvan–Newman

講義第 42 頁：一個三角形和一個 K₄ 用一條橋連起來（m = 10）。依講義分法 Q₁ = Q₂ = 0.1775、Q = 0.355。點節點可以換它的社群（三種顏色輪流）；或按「移除介數最高的邊」跑 Girvan–Newman（邊上的數字是邊介數），連通的部分自動當成一個社群。

3. 演算法與方法

3.1 連結預測（Link Prediction，第 44～51 頁）

連結預測是給一個觀察到的網路 G = (V, E)，預測哪些沒觀察到的連結其實存在（缺失連結）或未來會形成（未來連結）。

  • 缺失連結：還原隱藏、沒觀察到的友誼。未來連結：未來的共同作者、未來的追蹤關係。相關任務：連結類型預測（合作 vs. 競爭；引用是當背景還是用了方法）。
  • 為什麼會形成連結：同質性原則（Homophily，興趣或研究主題相似的人會連在一起）、三元閉包（Triadic closure，有共同朋友的人可能變成朋友）。這兩個樣式就是相似度式連結預測的動機。
  • 局部相似度式：用每個節點的鄰域替每對沒有相連的節點打分數、排序。兩類：鄰域重疊（共同鄰居、Jaccard）與度數式（偏好連結）。
  • 學習式：把共同鄰居、Jaccard、Adamic–Adar、度數乘積當成節點對的特徵；正樣本是觀察到的邊，負樣本是抽樣的未連結節點對，訓練邏輯斯迴歸、決策樹或神經網路；或用 GNN 把節點編碼成嵌入，再用解碼器替候選連結打分。

3.2 資訊擴散（Information Diffusion，第 53～59 頁）

資訊擴散研究想法、行為或疾病怎麼透過網路傳開：哪些節點會被啟動、傳得多快、最後的串聯（cascade）有多大。應用：病毒式行銷與產品採用、謠言與新聞傳播、流行病模擬。

  • 漸進式擴散模型：每個節點是啟動或未啟動；一開始種子集合是啟動的；啟動的節點可能影響未啟動的鄰居；一旦啟動就一直保持啟動。
  • 時間 \(t_1\) 時 v 啟動、u 未啟動；若啟動成功，u 在 \(t_2 > t_1\) 變成啟動。成不成功由擴散規則決定。
線性門檻模型（LTM）獨立串聯模型（ICM）
啟動規則已啟動鄰居的影響力總和達到門檻一次獨立的啟動嘗試成功
邊的意義影響力權重 \(w_{v,u}\)啟動機率 \(p_{v,w}\)
直覺同儕影響力的累加一次一次的個別嘗試
跨回合每回合用目前所有已啟動的鄰居重新評估每條有向邊只有一次嘗試機會
  • LTM：每個節點的門檻 \(\theta_v\) 在擴散開始前從 Uniform[0, 1] 獨立抽一次、之後固定；已啟動的節點保持啟動；第 t + 1 步才啟動的節點，下一回合才開始貢獻影響力。
  • ICM：節點 v 在時間 t 啟動，就在 t + 1 對每個未啟動的出鄰居 w 嘗試一次（抽亂數 r < \(p_{vw}\) 就成功）；不管成不成功，之後都不能再對 w 嘗試；各邊的嘗試互相獨立；沒有新節點啟動時停止。
  • 影響力最大化：給預算 k，找 k 個節點的種子集合 S 讓 σ(S)（串聯結束時期望的啟動節點數）最大；LTM／ICM 定義擴散的動態，影響力最大化是在那個模型下最佳化種子選擇。

LTM 與 ICM 的擴散過程

點節點設定種子（綠色）。LTM：邊權重 = 1/度數（每個節點收到的權重總和是 1），節點下方的數字是門檻 θ；ICM：每條邊的成功機率都是 p。按「下一步」一回合一回合地擴散（黃色是這回合新啟動的）；「估計 σ(S)」用 1000 次模擬算期望的最終啟動數。補充這張圖是自己設的。

3.3 傳染病模型（第 62～67 頁）

傳染病模型把人分成 S（易感，Susceptible）、I（感染，Infected，可以傳染別人）、R（康復／移除，Recovered/Removed）；和漸進式啟動模型不同，有些模型允許康復或再次易感。

  • SI：感染後一直是感染，沒有康復（S → I）。
  • SIR：康復或移除後不會再易感（S → I → R）。
  • SIS：康復後沒有持久的免疫力（S → I → S）。
  • SIRS：免疫力是暫時的，之後又會變回易感（S → I → R → S）。
  • SI 模型假設封閉、均勻混合、沒有康復的族群：N = S(t) + I(t) 固定；β 是傳染係數（易感者和感染者接觸時傳染成功的機率）。

SI／SIR／SIS 曲線

講義第 65 頁：S = 90、I = 10、β = 0.01 → βSI = 9，也就是此刻每單位時間有 9 人被感染。調 β 與 γ 看曲線形狀；SIR 的感染人數會先升後降，SIS 會停在一個平衡值。

S 易感I 感染R 康復

待確認講義文字只擷取到第 67 頁 SIR 模型的 γ 定義（「每個感染者以 γ 的速率離開感染狀態」）與 \(dS/dt = -\beta SI\) 的開頭，之後的 SIR 方程式、SIS、SIRS 的細節沒擷取到。上面元件與下方公式中 SIR 的 \(dR/dt\)、SIS、SIRS 是 補充依標準模型整理，請對照原始投影片。

4. 公式整理

4.1 中心性（第 15～23 頁）

$$C_D(v) = \deg(v), \qquad C_D^{norm}(v) = \frac{\deg(v)}{n - 1}$$ $$C_B(v) = \sum_{s \ne v \ne t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$

\(\sigma_{st}\)：s 到 t 的最短路徑數；\(\sigma_{st}(v)\)：其中經過 v 的條數。

$$C_C(v) = \frac{1}{\sum_{u \ne v} d(v, u)}, \qquad C_C^{norm}(v) = \frac{n - 1}{\sum_{u \ne v} d(v, u)}$$ $$x_i = \frac{1}{\lambda}\sum_j A_{ij}\, x_j \quad \Leftrightarrow \quad Ax = \lambda x$$

A 是鄰接矩陣，λ 是 A 最大的特徵值。

4.2 模組度（第 40～41 頁）

$$Modularity = \sum_{s \in S}\left[\#\text{edges in } s - \text{expected }\#\text{edges in } s\right], \qquad E(i, j) = \frac{k_i k_j}{2m}$$ $$Q = \frac{1}{2m}\sum_{ij}\left(A_{ij} - \frac{k_i k_j}{2m}\right)\delta_{ij}$$

4.3 連結預測（第 47～50 頁）

$$CN(x, y) = |N(x) \cap N(y)|, \qquad Jaccard(x, y) = \frac{|N(x) \cap N(y)|}{|N(x) \cup N(y)|}$$ $$AA(x, y) = \sum_{z \in N(x) \cap N(y)} \frac{1}{\log |N(z)|}, \qquad PA(x, y) = |N(x)| \cdot |N(y)|$$

4.4 擴散（第 55、57 頁）

$$\text{LTM：} \sum_{u \in N^{in}(v) \cap A_t} w_{v,u} \ge \theta_v, \qquad \text{ICM：成功 若 } r < p_{vw}$$

4.5 傳染病模型（第 65～67 頁）

$$\text{SI：}\ \frac{dS}{dt} = -\beta SI, \qquad \frac{dI}{dt} = \beta SI$$ $$\text{SIR：}\ \frac{dS}{dt} = -\beta SI, \qquad \frac{dI}{dt} = \beta SI - \gamma I, \qquad \frac{dR}{dt} = \gamma I \quad \text{(後兩式為補充)}$$ $$\text{SIS（補充）：}\ \frac{dS}{dt} = -\beta SI + \gamma I, \qquad \frac{dI}{dt} = \beta SI - \gamma I$$

5. 範例演算

例一：介數中心性（第 17 頁）

  1. 路徑 A–B–C–D–E，每對節點只有一條最短路徑
  2. C 在 (A, D)、(A, E)、(B, D)、(B, E) 這 4 對的路徑上 → \(C_B(C) = 4\)
  3. B 在 (A, C)、(A, D)、(A, E) 這 3 對上 → 3；D 同理 3
  4. A、E 是端點，不在任何其他節點對的路徑中間 → 0 A–E 的度都是 1、B–D 的度都是 2：度中心性分不出 B、C、D，介數可以。

例二：接近中心性（第 20 頁）

  1. 圖：A–B–C–D–E，再加上 C–F（n = 6）
  2. C 到其他點的距離：A 2、B 1、D 1、E 2、F 1，總和 7 → 正規化 5/7 ≈ 0.714
  3. A：B 1、C 2、D 3、E 4、F 3 → 13 → 5/13 ≈ 0.385；F：C 1、B 2、D 2、A 3、E 3 → 11 → 5/11
  4. B、D 各是 9 → 5/9 C 在正中間，到每個人都很近；F 雖然只有一個鄰居，但掛在中心 C 上，接近度比端點 A、E 高。

例三：特徵向量中心性怎麼穩定（第 22 頁）

  1. 三點路徑 A–B–C，一開始每人 1 分
  2. 每回合：保留自己的分數再加上鄰居的分數，所有節點同時更新，再用同一個倍數縮放
  3. 收斂後比例是 A : B : C = 0.7071 : 1 : 0.7071，鄰居分數和 = 1、1.4142、1
  4. B 的鄰居分數和 1.4142 = λ × 1，A 的 1 = λ × 0.7071 → λ = 1.4142 = \(\sqrt{2}\) 分數的相對比例在「用鄰居分數總和重新打分」之後不變，這就是 \(Ax = \lambda x\)。補充「保留自己的分數」是對 A + I 做冪次迭代，特徵向量和 A 一樣，但可以避免在二部圖上來回震盪。

例四：模組度（第 42 頁）

  1. m = 10，2m = 20。社群 1：3 條內部邊（\(\sum A_{ij}\) = 6），度數總和 7；社群 2：6 條內部邊（12），度數總和 13
  2. \(Q_1 = \frac{1}{20}\left(6 - \frac{7 \times 7}{20}\right) = \frac{6 - 2.45}{20} = 0.1775\)
  3. \(Q_2 = \frac{1}{20}\left(12 - \frac{13 \times 13}{20}\right) = \frac{12 - 8.45}{20} = 0.1775\)
  4. Q = 0.1775 + 0.1775 = 0.355 > 0 群內邊比虛無模型的期望多，是個不錯的分法。補充講義沒畫出圖的文字，這組數字剛好對應「三角形 + K₄ + 一條橋」，模組度元件就用這張圖。

例五：SI 模型（第 65 頁）

  1. S = 90、I = 10、β = 0.01
  2. \(\beta SI = 0.01 \times 90 \times 10 = 9\) 此刻每單位時間有 9 個新感染者；S 變少、I 變多之後，速率也會跟著變。

7. 複習問題

7.1 選擇題

1. 某節點只有 2 個鄰居，卻是連接兩個大社群的唯一通道。它哪個中心性最高？

(B)。兩個社群之間的所有最短路徑都要經過它，所以介數很高；度只有 2。中心性計算器選「兩群加一座橋」可以看到。

2. 模組度 Q > 0 代表什麼？

(C)。Q 是觀察到的群內邊比例減去期望比例；全部放同一群時 Q = 0。

3. 哪一個連結預測分數「不需要兩個節點有共同鄰居」也可能很高？

(D)。PA = |N(x)| × |N(y)|，只看兩端的度數。其他三個沒有共同鄰居時都是 0。

4. 在 ICM 中，節點 v 嘗試啟動鄰居 w 失敗後會怎樣？

(A)。ICM 每條邊只有一次嘗試機會。w 仍可能被其他新啟動的鄰居啟動。

7.2 觀念題

1. 為什麼 Girvan–Newman 刪的是「介數最高」的邊，而不是隨便一條邊？

看解答
社群之間的邊很少，所以兩個社群之間的最短路徑都得擠過這幾條橋，橋的邊介數特別高；社群內部的邊有很多替代路徑，介數低。反覆刪最高的邊，就會先把社群之間的橋切斷。刪完要重算，因為剩下的最短路徑會改走別條橋。

2. Adamic–Adar 為什麼要給度數小的共同鄰居比較大的權重？

看解答
如果共同鄰居是名人（度數很大），兩個人都認識他並不稀奇，也不代表兩人有交集；如果共同鄰居是只有少數朋友的人，兩人同時認識他就是比較強的證據。所以權重用 1/log(度數)：冷門的共同鄰居提供更強的證據。

3. 在講義的 6 點圖中，為什麼 {1, 2, 3, 4, 5} 是 2-clique 卻不是 2-clan？

看解答
在原圖中，4 和 5 可以走 4–6–5，距離是 2，所以集合內每對的距離都 ≤ 2，是 2-clique。但只看集合內部（導出子圖，沒有 6），4 到 5 要走 4–2–3–5，距離 3 > 2，直徑超過 2，所以不是 2-clan。

7.3 計算題

1. 星形圖：中心 C 連到 A、B、D、E（n = 5）。算 C 和 A 的正規化度中心性、介數與正規化接近中心性。

看解答
C：度 4/4 = 1；介數 = 葉子之間的 \(\binom{4}{2}\) = 6 對都經過 C → 6；接近 = 4/(1 × 4) = 1。A：度 1/4 = 0.25；介數 0；到 C 1、到其他 3 個葉子各 2 → 總和 7 → 4/7 ≈ 0.571。

2. x 的鄰居 {a, b, c, d}、y 的鄰居 {c, d, e}，且 deg(c) = 2、deg(d) = 4。算 CN、Jaccard、AA（自然對數）、PA。

看解答
交集 {c, d} → CN = 2；聯集 {a, b, c, d, e} → Jaccard = 2/5 = 0.4；AA = 1/ln 2 + 1/ln 4 = 1.443 + 0.721 = 2.164；PA = 4 × 3 = 12。

3. SI 模型 N = 100、β = 0.005。I = 20 和 I = 50 時，新感染的速率各是多少？

看解答
I = 20：S = 80 → 0.005 × 80 × 20 = 8。I = 50：S = 50 → 0.005 × 50 × 50 = 12.5。S × I 在兩者各半時最大，所以感染速度在一半人被感染時最快，之後易感的人變少就慢下來（S 形曲線）。

7.4 情境應用題

1. 公司預算只夠送 5 位網紅新產品，想讓口碑擴散最廣。只挑追蹤數最高的 5 人有什麼問題？該怎麼選？

看解答
追蹤數是度中心性，但高度數的人可能都在同一個圈子、粉絲高度重疊，擴散範圍重複。這是影響力最大化問題：在選定的擴散模型（LTM 或 ICM）下，選 5 個種子讓期望啟動數 σ(S) 最大。補充常用貪婪法：每次加入「能讓 σ(S) 增加最多」的節點（用模擬估計 σ），自然會挑到不同社群、彼此互補的人；介數高的「連結者」也很有價值。

8. 一頁速記

  1. 社群網路 G = (V, E)：節點是行動者、邊是關係；有向／無向、加權／不加權。四大任務：中心性、社群偵測、連結預測、資訊擴散。
  2. 度 = 鄰居數（正規化 ÷ (n − 1)）；介數 = 經過我的最短路徑比例總和；接近 = (n − 1)/Σ 距離；特徵向量 Ax = λx。
  3. 講義：路徑介數 0, 3, 4, 3, 0；接近 5/13、5/9、5/7…；三點路徑特徵向量 0.7071、1、0.7071、λ = √2。
  4. 社群偵測 = 以連結樣式分群。成員式：clique（NP-hard）、n-clique（原圖距離）、n-club（子圖直徑）、n-clan（兩者都滿足）、k-plex、k-core。
  5. 群體式：KL（平衡二分、交換）、GN（反覆刪邊介數最高的邊）、模組度最大化。
  6. \(Q = \frac{1}{2m}\sum(A_{ij} - \frac{k_ik_j}{2m})\delta_{ij}\)；講義 0.1775 + 0.1775 = 0.355。
  7. 連結形成：同質性、三元閉包。CN、Jaccard（÷ 聯集）、AA（Σ 1/log deg）、PA（deg × deg）；學習式用這些當特徵或用 GNN。
  8. LTM：鄰居權重和 ≥ θ（θ 抽一次固定）；ICM：每條邊一次機會、機率 p。漸進式：啟動後不會變回。
  9. 影響力最大化：預算 k，選 S 讓 σ(S) 最大。
  10. SI（無康復）、SIR（康復免疫）、SIS（不免疫）、SIRS（暫時免疫）；SI：dI/dt = βSI，講義例 0.01 × 90 × 10 = 9。
